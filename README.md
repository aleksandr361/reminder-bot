# Бот-напоминалка для Telegram

Напоминания однократные, каждый час, каждый день или по дням недели — с учётом часового пояса пользователя.

## Запуск (Windows)

1. **Установить библиотеки** (один раз). В PowerShell в этой папке:

   ```
   py -m pip install -r requirements.txt
   ```

2. **Указать токен.** Скопируйте `.env.example` в файл `.env` и впишите токен от [@BotFather](https://t.me/BotFather):

   Проще всего из PowerShell в этой папке:

   ```
   copy .env.example .env; notepad .env
   ```

   В открывшемся Блокноте замените `вставьте_сюда_токен` на свой токен и сохраните. Должна получиться строка:

   ```
   BOT_TOKEN=123456789:AAH...
   ```

   Файл `.env` никому не пересылайте — по токену можно управлять ботом.

3. **Запустить:** дважды щёлкнуть `start.bat` или выполнить `py main.py`.
   Пока окно открыто, бот работает. Остановить — `Ctrl+C` или закрыть окно.

Напоминания хранятся в `reminders.db` рядом с ботом и переживают перезапуск.

## Что умеет

- `/start` — приветствие и выбор часового пояса (по геолокации или вручную)
- `/remind`, «➕ Новое напоминание» или просто текст боту — создать напоминание
- Типы повторения: однократно; каждые N часов (от текущего момента или от выбранного времени);
  каждые N дней с даты начала; по дням недели; каждый месяц — в выбранные числа, в последний день
  или за N дней до конца месяца
- Напоминание — текст или вложение: фото, видео, файл, голосовое, кружок, GIF, стикер
- Время — кнопкой или вручную (`1015`, `9:30`); «❌ Отмена» на любом шаге
- `/list` или «📋 Мои напоминания» — список с кнопкой отмены
- `/timezone` — сменить часовой пояс
- В сработавшем напоминании: отложить на 10 / 30 / 60 минут (отложенное придёт с пометкой), «Готово», отменить серию

## Файлы

| Файл | Что делает |
|---|---|
| `main.py` | диалоги и обработка кнопок |
| `storage.py` | база SQLite: пользователи и напоминания |
| `keyboards.py` | все кнопки и календарь |
| `texts.py` | тексты правил повторения, даты, склонения |
| `scheduler.py` | раз в 10 секунд отправляет наступившие напоминания и переносит повторяющиеся |
| `deploy/` | установка и обновление на сервере |
| `tests/` | автотесты |

## Бот на сервере (Debian/Ubuntu)

На сервере бот работает круглосуточно как служба `reminder-bot`:
сам запускается при включении сервера и перезапускается, если упадёт.
Код и `venv` — в `/opt/reminder-bot`, там же `.env` с токеном и база `reminders.db`.

**Первая установка** (все команды — из PowerShell в папке бота):

1. Укажите сервер: создайте `deploy\server.txt` со строкой вида `root@1.2.3.4`
   (пример — `deploy\server.example.txt`; сам `server.txt` в git не попадает).
2. Один раз добавьте на сервер свой SSH-ключ (спросит пароль root):

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\add_ssh_key.ps1
   ```

3. Установите бота (возьмёт токен из локального `.env`):

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\update_server.ps1
   ```

**Обновить код** — та же команда `update_server.ps1`: токен и напоминания на сервере сохранятся.
**Сменить токен** — впишите новый в `.env` и запустите `update_server.ps1 -Token`.

**Не запускайте бота на компьютере**, пока он работает на сервере: два бота с одним токеном мешают друг другу.

Логи и управление (подставьте адрес своего сервера):

```
ssh root@<сервер> "journalctl -u reminder-bot -n 50 --no-pager"   # последние логи
ssh root@<сервер> "systemctl restart reminder-bot"                # перезапустить
ssh root@<сервер> "systemctl status reminder-bot --no-pager"      # состояние
```
